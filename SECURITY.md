# Security Policy

[日本語](#セキュリティポリシー)

## Supported versions

Only the latest release is looked at. Older versions do not receive fixes.

## Reporting a vulnerability

Please report a vulnerability **privately** through GitHub:
open the **Security** tab of this repository and choose
**Report a vulnerability** (GitHub's private vulnerability reporting).

Please do **not** open a public issue for a vulnerability.

A useful report includes the version, the steps to reproduce it, and what
an attacker could do with it.

## What to expect

N3MemoryCore is provided **as is**, without support or warranty, by an
individual developer. Reports are read, but there is **no promised time** for a
reply or a fix. Serious problems are fixed in a later release where possible.

## Scope

This policy covers the code and the specification in this repository only.
Problems in other software (for example Redis Stack, Python packages or the
MCP client) should be reported to the project that maintains it.

# セキュリティポリシー

[English](#security-policy)

## 対象の版

最新のリリースだけを見ます。古い版は修正しません。

## 脆弱性の報告

脆弱性は、GitHub から**非公開で**報告してください。
このリポジトリの **Security** タブを開き、**Report a vulnerability** を選びます
(GitHub の非公開の脆弱性報告)。

脆弱性については、公開の Issue を作らないでください。

報告には、版、再現の手順、攻撃者が何をできるかを書いてもらえると助かります。

## 対応について

N3MemoryCore は、個人の開発者が**現状のまま**、サポートや保証なしで提供して
います。報告は読みますが、返事や修正の**時期は約束しません**。重大な問題は、
できる範囲で後のリリースで直します。

## 範囲

このポリシーの対象は、このリポジトリのコードと指示書だけです。ほかのソフトウェア
(Redis Stack、Python のパッケージ、MCP クライアントなど)の問題は、それぞれを
管理しているプロジェクトに報告してください。
